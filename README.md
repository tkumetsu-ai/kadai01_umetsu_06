## ⑤工夫した点・こだわった点
- チーズ職人養成学校のサイトであることがわかるようなメインビジュアルを設定
- LPの目的は説明会の募集であると想定し、画面上に常に「説明会に申し込む」ボタンが表示されるようにした。
- 問い合わせフォームでは、問い合わせ区分を設け、「説明会お申込み」にチェックすると、説明会の候補日程が表示されるようにした。
- サイトのカラーはコントラストを意識して、視認性の高いカラーを設定。
- 共通化できるclassは同じ値を設定することで、cssの変更作業を簡略化しようとした。
- 最初にClaudeで基本的な構成を作成してもらったあとで、仕様書と見比べながら手作業で修正を行ったことで、htmlやcssの基本的な書き方を学ぶことができた。
- 手作業で修正したあとにClaudeにおかしな点がないかをチェックさせることで、入力間違いや間違った使い方をしている部分を気づくことができた。
